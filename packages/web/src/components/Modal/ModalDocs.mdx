  # Modal

  <Status React="Prototype" Figma="https://www.figma.com/" />

  This is a Modal that should be used when an application requires a required action from the user or to communicate information to the user.

  ## Default

  By default, the Modal is closed.

  Pass `label` to name the dialog for assistive technology. When `label` is omitted, the name falls back to "dialog backdrop". Pass `closeLabel` to name the close button. When it is omitted, the button falls back to "dialog close button". Callers pass both strings.

  `Dialog` uses its visible `title` as the dialog name unless `label` is set.
